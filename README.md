# Laboratorio IA + Inglés · página del taller
1. En GitHub cree un repositorio nuevo y público (por ejemplo, `taller-ia`).
2. Suba `index.html` y la carpeta `img` completa (Add file > Upload files).
3. Vaya a Settings > Pages, elija la rama `main` y la carpeta `/ (root)`, y guarde.
4. En uno o dos minutos la página queda en `https://SU-USUARIO.github.io/taller-ia/`.
5. Enlaces: abra `index.html`, busque `const ENLACES` y pegue cada URL entre las comillas (juego, cuadernos).
6. Foto en «Quién facilita»: guarde la foto como `img/christiam.jpg` y en `index.html` cambie `data-foto="no"` por `data-foto="img/christiam.jpg"`. Mientras tanto se ven las iniciales CP.

Archivos: `index.html` (contenido), `css/taller.css` (diseño), `js/taller.js` (animaciones y botones), `img/` (imágenes).
